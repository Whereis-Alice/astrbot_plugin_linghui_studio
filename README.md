# 灵绘工坊

`astrbot_plugin_linghui_studio` 是面向 AstrBot 的文生图、图生图插件。它把绘图渠道、群权限、额度、提示词预设、人设图片和参考图集中到一个 Dashboard 页面中管理。

这个项目使用独立的插件名、数据目录、Web API 前缀、LLM 工具名和聊天指令，能够与上游插件同时安装而不抢占配置或命令。

## 适用版本

- AstrBot `>= 4.16, < 5`
- Python 依赖：`aiohttp`、`Pillow`、`PyMuPDF`
- QQ 头像图生图仅适用于发送者 ID 为 QQ 数字账号的平台适配器。

## 安装

在 AstrBot Dashboard 的插件页通过仓库地址安装，或将本目录放入 AstrBot 的插件目录后重载插件。

```text
https://github.com/Whereis-Alice/astrbot_plugin_linghui_studio
```

安装后打开 AstrBot Dashboard 的“插件页面”，进入“灵绘工坊”。首次使用前至少完成下面两项：

1. 在“绘图渠道”添加一个渠道，填写渠道 ID、接口模式、地址、API Key 和模型。
2. 在“权限与额度”把要开放的群号加入“允许生图的群白名单”。

默认采用“只允许群白名单”模式，避免未配置时在所有群里产生绘图请求和费用。

## 快速开始

假设 AstrBot 的命令前缀为 `#`：

```text
#灵绘 画 一只穿雨衣的橘猫站在雨后的霓虹街道，电影感，16:9
#灵绘 手办化
#灵绘 手办化 透明圆形底座，产品摄影
#灵绘头像图生图 复古胶片人像，暖色自然光
```

`#灵绘 手办化` 等预设命令需要附带图片、回复带图消息，或在提示词中明确使用上文图片。`#灵绘 画` 没有图片时为文生图；带图片时会把图片作为图生图参考。

## 频道与回退

在 Dashboard 的“绘图渠道”中按优先级从上到下添加渠道：

| 字段 | 用途 |
| --- | --- |
| 渠道 ID | 唯一标识，例如 `primary`、`backup_1`。只能使用字母、数字、下划线和连字符。 |
| 接口模式 | `openai_image`、`openai_chat`、`gemini_official` 或 `custom_endpoint`。 |
| 地址与 API Key | 每个渠道独立保存，Key 支持多行轮询。 |
| 默认模型 | 图生图默认模型；可单独填写文生图模型。 |
| 允许作为回退渠道 | 开启后，前面的渠道返回错误时会继续尝试它。 |

运行时可由管理员快速切换主渠道：

```text
#灵绘通道
#灵绘通道 primary
#灵绘通道 自动
```

切换主渠道不会关闭回退。选择 `primary` 后，请求会先走 `primary`；如果失败，仍会按列表顺序尝试其他允许回退的渠道。所有渠道均失败时才返回失败信息。

没有配置“绘图渠道”时，插件仍支持旧式单接口字段作为兼容模式，但新安装建议使用渠道列表。

## 权限与额度

灵绘将“是否可以生图”和“是否扣次数”明确分开：

1. 用户黑名单、群黑名单优先拒绝。
2. 如果填写了用户白名单，只有名单内用户可以使用。
3. 当群聊访问模式为“只允许群白名单”时，只有 `group_whitelist` 中的群能生图。
4. 用户/群无限次数名单只跳过额度扣除，**不会**跳过黑名单、用户白名单或群白名单。
5. 管理员默认额度豁免，但生图时仍需要通过黑名单、用户白名单和群白名单校验；可在 Dashboard 关闭这项豁免。

这意味着：把群号加到“允许生图的群白名单”后，群成员可以生图，但仍会消耗个人或群额度。只有再加到“群无限次数名单”才不扣额度。

额度可在 Dashboard 中增加或重置；也可启用签到，由用户发送 `#灵绘签到` 领取个人额度。`#灵绘额度` 可以查看当前余额。

## 提示词翻译与优化

插件可选地调用一个**单独配置**的 OpenAI 兼容聊天模型处理提示词：

- 开启“生成前翻译为英文”：保留原意、专有名词、比例和安全限制，输出英文提示词。
- 开启“生成前优化提示词”：将提示词整理为更适合图像模型的表达。
- 两者同时开启时，先翻译再优化。

在“提示词与预设”页面填写提示词模型的地址、API Key、翻译模型、优化模型和系统提示词。提示词模型超时或返回异常时，插件会记录日志并直接使用原提示词，不会中断绘图渠道的回退流程。

## QQ 头像图生图

```text
#灵绘头像图生图 <提示词>
```

该命令会下载发送者 QQ 头像，并将其作为唯一的参考图发送给当前绘图渠道。它会使用同一套群白名单、额度、渠道回退和提示词处理规则。若当前平台不提供 QQ 数字账号，会提示改为直接发送参考图。

## Dashboard

AstrBot 会自动发现 `pages/linghui-studio/`。Dashboard 提供：

- 绘图渠道、接口地址、模型、密钥、启用状态与回退顺序。
- 当前主渠道选择。
- 群白名单、黑名单、用户白名单、无限次数名单。
- 用户/群额度、签到开关、签到奖励和今日统计。
- 提示词预设的增删改，并与聊天侧新增的自定义预设同步。
- 人设名称、描述、风格、触发词、默认场景、场景预设和人设参考图。
- 每个预设自己的参考图集合。
- 提示词翻译/优化模型及系统提示词。

出于安全考虑，页面重新加载时不会返回已保存的完整 API Key，只显示掩码。留空保存会保留原 Key；填写新值会替换它；勾选“清除已保存的 API Key”后保存可明确删除旧 Key。修改渠道 ID 时，未重新填写的已保存 Key 也会一并保留。

## 常用命令

所有命令都使用“灵绘”命名空间，避免与旧插件冲突。

| 命令 | 权限 | 说明 |
| --- | --- | --- |
| `#灵绘 画 <提示词>` | 已授权用户 | 文生图；带图时可作为图生图。 |
| `#灵绘 <预设名> [追加要求]` | 已授权用户 | 调用 Dashboard 中的预设。 |
| `#灵绘文生图 <提示词>` | 已授权用户 | 显式文生图。 |
| `#灵绘头像图生图 <提示词>` | 已授权用户 | 以发送者 QQ 头像作为参考图。 |
| `#灵绘签到` | 已授权用户 | 领取每日额度。 |
| `#灵绘额度` | 已授权用户 | 查看个人和群额度。 |
| `#灵绘人设拍照 [场景] [要求]` | 已授权用户 | 使用已配置的人设参考图生成照片。 |
| `#灵绘帮助` | 已授权用户 | 查看聊天侧帮助。 |
| `#灵绘通道 [ID/自动]` | 管理员 | 查看或切换主绘图渠道。 |
| `#灵绘模型 [序号/模型名]` | 管理员 | 切换兼容单接口模式的默认模型。 |
| `#灵绘预设列表` | 已授权用户 | 查看预设列表。 |
| `#灵绘预设添加`、`#灵绘预设删除` | 管理员 | 管理预设；复杂编辑建议使用 Dashboard。 |
| `#灵绘统计` | 管理员 | 查看当天成功生成统计。 |
| `#灵绘加用户额度`、`#灵绘加群额度` | 管理员 | 增加额度；Dashboard 可直接重置。 |

插件还保留了批量处理、PDF 打包、上下文图像延续和 LLM 工具能力；相关指令同样以 `灵绘` 开头，完整配置建议在 Dashboard 中完成。

## 配置与数据

配置 schema 位于 [`_conf_schema.json`](./_conf_schema.json)。运行时文件由 AstrBot 保存在插件专属数据目录：

- 用户和群额度、签到记录、每日统计。
- 自定义预设和预设缩略图。
- 人设参考图和预设参考图。
- 命令动态配置备份。

图片与 API Key 不会被上传到本仓库。请自行确认所接入渠道的隐私政策、图像内容规则和费用策略。

## 排障

| 现象 | 排查方式 |
| --- | --- |
| 提示“群不在白名单” | 在 Dashboard 的“允许生图的群白名单”填入群号，保存后重试。 |
| 群已在白名单但仍提示额度不足 | 这是预期行为：白名单只开放使用权限。增加额度，或将群加入“群无限次数名单”。 |
| 主渠道报错 | 检查渠道地址、模型和 Key；确认后续渠道已启用且勾选“允许作为回退渠道”。 |
| 没有回退 | 发送 `#灵绘通道` 检查主渠道和列表顺序；查看 AstrBot 日志中的 `Linghui` 渠道错误。 |
| 提示词处理失败 | 检查单独的提示词模型地址、Key 和模型名；处理失败不会阻断原提示词绘图。 |
| QQ 头像图生图不可用 | 确认使用 QQ 数字账号的平台适配器，或改为直接发送图片进行图生图。 |
