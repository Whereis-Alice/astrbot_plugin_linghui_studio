# 灵绘工坊

`astrbot_plugin_linghui_studio` 是 AstrBot 的文生图、图生图与图像工作流插件。它保留了上游手办化插件的完整功能集，并补充了受控群白名单、独立无限额度名单、多渠道自动回退、提示词翻译/优化和可视化 Dashboard。

插件使用独立的插件 ID、数据目录、Web API 路径和 LLM 工具名。聊天命令默认是短命令；当需要与其他绘图插件共存时，可以在 Dashboard 设置命名空间并关闭短命令，以避免命令冲突。

## 适用版本

- AstrBot `>= 4.16, < 5`
- Python 依赖：`aiohttp`、`Pillow`、`PyMuPDF`
- QQ 头像图生图需要当前平台能提供发送者的 QQ 数字账号。

## 安装

在 AstrBot Dashboard 的插件页使用仓库地址安装，或将本目录放入 AstrBot 插件目录后重载：

```text
https://github.com/Whereis-Alice/astrbot_plugin_linghui_studio
```

首次使用请在“灵绘工坊”插件页面完成三项配置：

1. 在“绘图渠道”添加至少一个渠道，填写接口模式、地址、API Key 和模型。
2. 在“权限与额度”将可使用的群加入“允许生图的群白名单”。
3. 为用户或群发放额度，或将其加入对应的无限次数名单；默认个人额度开关是开启的。

默认群聊访问模式为白名单，未加入 `group_whitelist` 的群不会发起生图请求。

## 命令模式

以下示例假设 AstrBot 的命令前缀为 `#`。

默认不需要“灵绘”前缀：

```text
#文生图 雨后的霓虹街道，一只穿雨衣的橘猫，电影感，16:9
#画 复古胶片人像，暖色自然光
#bnn 复古胶片人像，暖色自然光
#手办化
#预设列表
```

`#画` 是可配置的自定义绘图子命令，默认值为“画”。它没有图片时执行文生图；携带图片、回复图片消息或明确引用上文图片时执行图生图。上游兼容指令 `#bnn` 始终保留，功能与 `#画` 相同；当管理员改了 `extra_prefix` 时，`#bnn` 仍可继续使用。`#手办化` 等预设需要图片输入。

### 与其他绘图插件共存

在 Dashboard 的“运行设置”中：

1. 将“可选命令命名空间”设为例如 `绘图`。
2. 关闭“启用不带命名空间的直接命令”。

之后所有入口都使用命名空间加空格：

```text
#绘图 文生图 一只橘猫
#绘图 画 一只橘猫
#绘图 bnn 一只橘猫
#绘图 手办化
#绘图 通道 primary
#绘图 lm列表
```

命名空间模式同时接受上游的预设、参考图和管理命令别名，例如 `lm列表`、`lma`、`lmref添加`、`图片转PDF`。插件 ID、配置数据、Web API 和 LLM 工具始终是独立的。

## 功能总览

| 能力 | 说明 |
| --- | --- |
| 文生图与图生图 | 支持当前消息图片、回复图片、图片 URL、最近会话图片和预设参考图。 |
| 44 个默认预设 | 完整保留上游默认预设，可在 Dashboard 或聊天命令中增删改。 |
| 多渠道回退 | 按渠道顺序调用；主渠道失败后自动尝试启用了回退的后续渠道。 |
| 访问与额度 | 群白名单只授予使用权；用户/群无限次数名单只免额度，不绕过权限规则。 |
| 提示词处理 | 可分别启用翻译和优化，使用独立 OpenAI 兼容聊天模型，故障时回退原提示词。 |
| QQ 头像图生图 | 以发送者 QQ 头像为参考图，复用同一套权限、额度和回退逻辑。 |
| 人设模式 | 人设参考图、场景提示词、关键词触发、人物合影和人设拍照。 |
| 批量与 PDF | 批量处理上下文图片、并发重试、图片打包 PDF、LLM 工具调用。 |
| Dashboard | 管理渠道、模型、提示词、参考图、人设、权限、签到和额度。 |

## 绘图渠道与回退

Dashboard 的“绘图渠道”从上到下定义优先级。每条渠道可独立设置：

| 字段 | 用途 |
| --- | --- |
| 渠道 ID | 唯一标识，例如 `primary`、`backup_1`。仅允许字母、数字、下划线和连字符。 |
| 接口模式 | `openai_image`、`openai_chat`、`gemini_official`、`custom_endpoint`。 |
| 地址与 API Key | 渠道独立保存；多个 Key 可按行填写并轮询。 |
| 默认模型 | 图生图模型；可另填文生图模型。 |
| 允许作为回退渠道 | 前方渠道失败时，是否继续尝试此渠道。 |

管理员可快速查看或切换主渠道：

```text
#通道
#通道 primary
#通道 自动
```

选择 `primary` 后，请求先走该渠道；发生错误时仍会继续尝试后续允许回退的渠道。没有配置渠道列表时，插件会兼容旧式单接口字段。

## 权限、黑白名单与额度

访问控制和额度豁免是两件独立的事，优先级如下：

1. 用户黑名单、群黑名单优先拒绝。
2. 填写了用户白名单后，只有名单内用户可用。
3. 群聊白名单模式下，只有 `group_whitelist` 中的群可用。
4. 管理员额度豁免、用户无限次数、群无限次数只跳过额度扣除，不会跳过前三项。
5. 个人额度不足时，可选用群额度作为备用额度。

因此，将群号加入群白名单后，群成员可以生图，但仍会消耗额度。只有再加入“群无限次数名单”才会免额度。私聊默认关闭，可在 Dashboard 显式开启。

签到可按固定次数或随机次数发放个人额度。Dashboard 支持查看、增加和重置用户/群额度。

## 提示词翻译与优化

在“提示词与预设”页可分别打开：

- “生成前翻译为英文”：保留原意、专有名词、比例与安全限制。
- “生成前优化提示词”：整理为更适合图像模型的表达。

两项同时开启时先翻译后优化。该模型使用独立的地址、API Key 和模型名；超时或失败时会记录日志并直接使用原始提示词，不会中断渠道回退。

## QQ 头像图生图

```text
#头像图生图 复古胶片人像，暖色自然光
```

插件会下载发送者 QQ 头像并作为唯一参考图。当前平台不能提供 QQ 数字账号时，会提示改为直接发送参考图。

## 聊天命令

所有普通用户命令都会先经过权限和额度校验；标有“管理员”的命令还需要 AstrBot 管理员权限。

### 绘图与预设

| 命令 | 说明 |
| --- | --- |
| `#画 <提示词>` | 自定义绘图；是否图生图取决于是否附带或引用图片。 |
| `#bnn <提示词>` | 上游兼容的自定义绘图指令，行为与 `#画` 相同，始终保留。 |
| `#文生图 <提示词>` | 显式文生图，可使用文生图专用模型。 |
| `#头像图生图 [提示词]` | 使用发送者 QQ 头像作为参考图。 |
| `#<预设名> [追加要求]` | 调用默认或自定义预设。 |
| `#预设列表` | 查看预设列表。 |
| `#预设查看 <预设名>` | 查看一个预设的提示词。 |
| `#预设添加 <名称>:<提示词>` | 添加或更新预设（管理员）。 |
| `#预设删除 <名称>` | 删除自定义预设并清理其参考图（管理员）。 |

### 额度与渠道

| 命令 | 说明 |
| --- | --- |
| `#签到` | 领取每日额度。 |
| `#额度 [用户]` | 查看个人及当前群额度；管理员可指定用户。 |
| `#通道 [ID/自动]` | 查看或切换主渠道（管理员）。 |
| `#接口模式 <模式>` | 修改兼容单接口模式（管理员）。 |
| `#模型 [序号/模型名]` | 查看或切换兼容单接口模型（管理员）。 |
| `#统计` | 查看今日使用统计（管理员）。 |
| `#加用户额度 <QQ号> <次数>` | 增加用户额度；也支持 `@用户 <次数>`（管理员）。 |
| `#加群额度 <群号> <次数>` | 增加群额度；在群内只填次数时使用当前群（管理员）。 |

### 密钥、缓存与上下文

| 命令 | 说明 |
| --- | --- |
| `#添加密钥 <key...>` | 添加兼容单接口 Key（管理员）。 |
| `#密钥列表` | 查看已配置 Key 的掩码列表（管理员）。 |
| `#删除密钥 <序号/all>` | 删除一个或全部 Key（管理员）。 |
| `#预设图片清理 [天数]` | 清理过期的生成缓存（管理员）。 |
| `#预设图片统计` | 查看生成缓存占用（管理员）。 |
| `#上下文状态` | 查看会话消息与图片上下文状态（管理员）。 |
| `#清除上下文` | 清除当前会话上下文与图片缓存（管理员）。 |
| `#测试智能判断 <文本>` | 仅测试 LLM 图像任务判断，不生成图片（管理员）。 |

### 参考图、人设、批量与 PDF

| 命令 | 说明 |
| --- | --- |
| `#预设参考图添加 <预设名>` | 为预设保存当前或引用消息中的图片（管理员）。 |
| `#预设参考图查看/清除 <预设名>` | 查看或清除预设参考图（管理员）。 |
| `#预设参考图删除 <预设名> <序号>` | 删除一张预设参考图（管理员）。 |
| `#预设参考图统计` / `#预设参考图列表` | 查看预设参考图统计或列表（管理员）。 |
| `#人设拍照 [场景] [要求]` | 使用人设参考图生成照片。 |
| `#人设参考图添加/查看/清除` | 管理人设参考图（管理员）。 |
| `#人设场景列表` / `#人设状态` | 查看人设场景或状态。 |
| `#批量处理 <预设名> [规则]` | 批量处理上下文中的图片。 |
| `#打包PDF` | 将当前消息或会话中的有效图片打包为 PDF。 |
| `#帮助` | 显示可自定义的聊天帮助。 |

## LLM 工具与自动判断

启用 LLM 工具后，AstrBot 可以调用独立的 `linghui_*` 工具执行用户状态检查、文生图、图生图、智能任务判断、批量并发处理、PDF 打包和人设拍照。开启“LLM 智能判断”后，插件会结合会话上下文判断文生图或图生图，并在触发后沿用相同的权限、额度、提示词处理和渠道回退流程。

## Dashboard

AstrBot 会自动发现 `pages/linghui-studio/`。页面包含：

- 绘图渠道、接口地址、模型、Key 掩码、启用状态和回退顺序。
- 可选命名空间与直接命令开关。
- 群/用户黑白名单、无限次数名单、签到和额度调整/重置。
- 44 个默认预设及自定义预设的增删改。
- 预设参考图与人设参考图的上传、查看和删除。
- 人设名称、描述、风格、触发词、默认场景和场景提示词。
- 提示词翻译/优化开关、独立模型、系统提示词和超时。

页面重新加载时不会回传完整 API Key，只显示掩码。留空保存会保留原 Key；勾选“清除已保存的 API Key”才会删除。

## 排障

| 现象 | 处理方式 |
| --- | --- |
| 群不在白名单 | 在 Dashboard 的“允许生图的群白名单”加入群号。 |
| 群已授权但提示额度不足 | 白名单只授予使用权；增加额度、关闭额度限制，或加入群无限次数名单。 |
| 主渠道报错 | 检查主渠道地址、模型和 Key，并确认后续渠道已启用且允许回退。 |
| 没有触发命令 | 检查 AstrBot 命令前缀、`prefix` 配置，以及命名空间/直接命令开关。 |
| 提示词处理失败 | 检查独立提示词模型的地址、Key 和模型名；失败时应自动回退原提示词。 |
| QQ 头像图生图不可用 | 确认平台可提供 QQ 数字账号，或直接发送参考图。 |

## 数据与许可

运行数据保存在 AstrBot 为本插件分配的数据目录，包括额度、签到、预设、人设图片、参考图和动态配置备份。API Key 与图片不会提交到本仓库。
