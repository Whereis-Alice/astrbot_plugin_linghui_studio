# 灵绘工坊

AstrBot 的文生图、图生图与人设图片插件。支持多渠道回退、QQ 头像参考图、预设与参考图管理、额度控制、批量任务和可视化 Dashboard。

项目使用独立的插件标识、配置数据目录、Dashboard 路径和 LLM 工具名称，可与上游插件及其他绘图插件并存。

## 功能

- 文生图、图生图、人设拍照和 QQ 头像参考图。
- 保留上游手办化插件的核心命令、预设和参考图能力，并支持扩展自定义预设。
- 渠道优先级、单渠道每日总额度、多模型有序回退、独立分辨率/比例和会话级切换。
- 群聊白名单、黑名单、用户/群额度和无限次数名单。
- 提示词翻译、优化、自定义反向提示词与预设安全限制。
- 自拍支持 LLM 在现有工具调用中自主决定穿搭与表情，可逐张安排多张照片，减少神态重复；也可切回每日固定模式。
- 批量生图、失败策略、图片转 PDF 和后台任务。
- 成功记录缓存、图生图原图留存、下载、收藏、锁定、筛选和统计。
- Dashboard 管理渠道、模型、预设、人设、权限、额度、缓存和主题；一键导入/导出渠道（含 Key）。
- `#bnn 渠道m 一只猫` 临时测试渠道 ID `m`；也支持 `#bnn --渠道 primary 一只蓝色小猫`，不写渠道参数沿用原路由。

## 安装

在 AstrBot Dashboard 的插件页使用仓库地址安装，或将插件目录放入 AstrBot 的插件目录后重载：

<https://github.com/Whereis-Alice/astrbot_plugin_linghui_studio>

首次使用：

1. 在“绘图渠道”添加至少一个渠道，填写接口地址、密钥和模型。
2. 在“权限与额度”配置允许生图的群、黑名单和额度。
3. 在“人设与参考图”上传人设图（需要人设拍照时）。
4. 在 Dashboard 的“运行设置”确认命令前缀、回退和缓存策略。

## 快速开始

以下示例使用 `#` 作为 AstrBot 唤醒词；如果你的唤醒词不同，请替换为实际值。

```text
#文生图 雨后的霓虹街道，一只穿雨衣的橘猫
#画 复古胶片人像，暖色自然光
#bnn @甲 @乙 两个人在雨后的街道合影
#手办化
#预设列表
#预设列表 说明
#人设拍照 咖啡店窗边，自然光
```

`#画` 没有参考图时是文生图，带图片、回复图片或引用上文图片时是图生图。`#bnn` 始终保留，并可按艾特顺序使用一个或多个 QQ 头像作参考图；艾特名称、群名、QQ 号和 ID 不会作为画面文字提示。

与其他绘图插件冲突时，在 Dashboard 设置命名空间（例如 `绘图`）并关闭直接命令，改用：

```text
#绘图 文生图 一只橘猫
#绘图 bnn @甲 两个人在海边
#绘图 手办化
```

## 权限与冷却

默认群聊采用白名单模式：只有“允许生图的群白名单”中的群可以生图；黑名单优先拒绝。无限次数名单只免除额度扣减，不能绕过白名单、黑名单或私聊开关。

手动指令冷却在 Dashboard 的“运行设置”中配置，按“QQ 用户 ID + 群号”独立计时，不同群互不影响；私聊按用户单独计时。它不影响 LLM 工具的生图冷却，设为 `0` 可关闭。

## 兼容性

- AstrBot `>= 4.16, < 5`
- Python 依赖：`aiohttp`、`Pillow`、`PyMuPDF`
- QQ 头像功能需要平台提供 QQ 数字账号。
