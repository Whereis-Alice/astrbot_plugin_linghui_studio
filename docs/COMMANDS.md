# 命令与使用

## 前缀

命令前缀由 AstrBot 顶层唤醒词决定，不是插件固定值。下面用 `#` 举例；也可以直接 @机器人，私聊通常不需要前缀。

## 绘图

| 命令 | 用法 |
| --- | --- |
| `#画` | 自定义绘图；带图片时自动图生图。别名可在配置中修改。 |
| `#bnn` | 上游兼容命令；功能同 `#画`，并支持 `@用户` 头像作为参考图。 |
| `#文生图` | 强制使用文生图流程。 |
| `#头像图生图` | 使用发送者自己的 QQ 头像作为参考图。 |
| `#人设拍照` | 使用已上传的人设图和场景提示词。 |
| `#预设名` | 调用预设，可在后面追加要求。 |

示例：

```text
#画 电影感城市夜景
#画 水彩风猫咪
#bnn @甲 @乙 两个人并肩站在海边
#文生图 复古海报风格
#头像图生图 穿着雨衣站在街角
#手办化
#人设拍照 图书馆窗边，下午阳光
```

`#bnn @甲 @乙 提示词` 不要求把艾特放在固定位置，只要消息中包含艾特对象即可；插件会按出现顺序去重并忽略机器人自身。若明确要求“不带名字、群名、QQ 号或 ID”，隐私限制会自动加强。

## 预设与参考图

```text
#预设列表
#预设列表 我的

#预设列表 文字

#预设列表 说明 手办
#预设查看 手办化
#预设参考图查看 手办化
#预设参考图清除 手办化
#人设参考图查看
```

## 渠道与模型

```text
#通道                 查看当前会话渠道
#通道 2               切换当前会话渠道
#通道 自动            恢复自动调度
#通道 全局 primary    修改全局默认渠道（管理员）
#模型 gpt-image-1     切换当前会话模型
#模型 全局 gpt-image-1 修改全局默认模型（管理员）
```

会话级切换不会影响其他群或私聊，覆盖会在配置的有效期后自动恢复。

## 额度与管理

```text
#签到
#额度
#统计
#帮助
#打包PDF
```

管理员可在 Dashboard 管理用户/群额度、无限次数名单、成功记录和任务中心。详细规则见[配置指南](CONFIGURATION.md)。

`#预设列表 说明` 会一行显示每个预设的用途；追加关键词可以筛选，例如 `#预设列表 说明 手办`。当前内置预设主要是图生图预设，需要图片或引用图片。没有参考图时，请使用 `#文生图` 或无图的 `#画`。
