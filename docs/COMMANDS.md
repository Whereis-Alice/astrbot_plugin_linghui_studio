# 命令与使用

## 前缀

命令前缀由 AstrBot 顶层唤醒词决定，不是插件固定值。下面用 `#` 举例；也可以直接 @机器人，私聊通常不需要前缀。

本文介绍日常使用；全部管理命令见[管理员命令](ADMIN_COMMANDS.md)，包括增加用户/群次数、预设管理、参考图、密钥和排障。

## 绘图

| 命令 | 用法 |
| --- | --- |
| `#画` | 自定义绘图；带图片时自动图生图。别名可在配置中修改。 |
| `#bnn` | 上游兼容命令；功能同 `#画`，并支持 `@用户` 头像作为参考图。 |
| `#文生图` | 强制使用文生图流程。 |
| `#头像图生图` | 使用发送者自己的 QQ 头像作为参考图。 |
| `#人设拍照` | 使用已上传的人设图和场景提示词。 |
| `#预设名` | 调用预设，可在后面追加要求。 |

示例：

```text
#画 电影感城市夜景
#画 水彩风猫咪
#bnn @甲 @乙 两个人并肩站在海边
#文生图 复古海报风格
#头像图生图 穿着雨衣站在街角
#手办化
#人设拍照 图书馆窗边，下午阳光
```

`#bnn @甲 @乙 提示词` 不要求把艾特放在固定位置，只要消息中包含艾特对象即可；插件会按出现顺序去重并忽略机器人自身。若明确要求“不带名字、群名、QQ 号或 ID”，隐私限制会自动加强。

## 预设与参考图

```text
#预设列表
#预设列表 我的
#预设列表 自带
#预设列表 文字
#预设列表 说明
#预设列表 说明 手办
#预设查看 手办化
```

这些列表和提示词查询可供普通用户使用。预设添加/删除、预设参考图与人设参考图的管理（包括查看）需要管理员，完整用法见[预设提示词与参考图管理](ADMIN_COMMANDS.md#预设提示词)。

## 渠道与模型

以下命令的查询与切换都需要 **AstrBot 管理员**身份，QQ 群管理员身份本身不算。

```text
#通道                 查看当前会话渠道
#通道 2               切换当前会话渠道
#通道 自动            清除会话选择，跟随全局配置
#通道 全局 primary    修改全局默认渠道（管理员）
#通道 全局 自动       全局恢复渠道列表顺序
#模型 gpt-image-1     切换当前会话模型
#模型 全局 gpt-image-1 修改全局默认模型（管理员）
```

开启会话级选择时，切换只影响 AstrBot 当前会话，覆盖会在配置的有效期后自动恢复。关闭对应的会话级选择后，普通切换也会修改全局配置。完整参数及兼容别名见[管理员命令](ADMIN_COMMANDS.md#绘图渠道与模型)。

## 额度与帮助

```text
#签到
#额度
#帮助
#打包PDF
#人设场景列表
```

管理员增加次数可直接用：

```text
#加用户额度 123456789 10
#加用户额度 @用户 10
#加群额度 987654321 50
#统计
```

这些命令都需要管理员。个人余额在群聊与私聊之间共用；补额度不会自动授予白名单访问权。更多查询、别名和范围说明见[管理员命令](ADMIN_COMMANDS.md#用户与群额度)。名单、重置额度、成功记录和任务中心也可在 Dashboard 管理，规则见[配置指南](CONFIGURATION.md)。

`#预设列表 说明` 会一行显示每个预设的用途；追加关键词可以筛选，例如 `#预设列表 说明 手办`。当前内置预设主要是图生图预设，需要图片或引用图片。没有参考图时，请使用 `#文生图` 或无图的 `#画`。
