# 配置指南

## 渠道与回退

在 Dashboard 的“绘图渠道”中按从上到下的顺序添加渠道。每条渠道可以单独设置接口模式、地址、API Key、默认模型、文生图模型、带参考图模型、上传格式和是否允许回退。

- `auto`：按模型和请求类型选择优先协议，并在明确的协议不兼容时有限回退。
- `openai_image`：优先 Images API。
- `openai_chat`：优先 Chat Completions。
- `gemini_official`、`grok`、`agnes`、`novelai`、`jimeng`：使用对应原生协议。
- `custom_endpoint`：使用完整自定义地址，不跨协议回退。

OpenAI 兼容站点通常只填写站点基础地址，例如 `https://example.com`，不要把 `/v1/images` 写进基础地址。纯文生图走 generations，带参考图走 edits；具体能力取决于服务商模型。

主渠道失败后，插件会尝试后续启用回退的渠道。连续失败的渠道会暂时冷却；可配置失败阈值、冷却时间、Key 重试次数以及是否遇到安全拒绝时继续回退。

## 权限与额度

### 群聊

- **允许生图的群白名单**：白名单模式下，只有名单中的群允许生图；留空表示没有群获得权限。
- **禁止生图的群黑名单**：黑名单优先级最高，命中的群始终禁止生图。
- **群无限次数名单**：只免除额度扣减，必须同时位于允许生图的群白名单中才有效。

### 用户与私聊

- 用户白名单/黑名单控制个人访问。
- 用户无限次数名单只免除额度扣减。
- 私聊是否允许使用由“允许私聊生图”控制；私聊额度按 QQ 用户 ID 计算。

### 手动指令冷却

`command_cooldown_seconds` 只限制手动指令和预设指令，包括 `#画`、`#bnn`、`#文生图`、`#头像图生图`、`#人设拍照`。冷却键为 `(QQ 用户 ID, 群号)`：同一用户在不同群互不影响，私聊单独计时。LLM 工具使用另一套 `llm_cooldown_seconds`，两者互不干扰；设置为 `0` 关闭。

## 提示词与预设

可分别开启提示词优化和翻译，并为两个模型设置独立地址、模型和系统提示词。处理失败时默认回退原提示词。

自定义反向提示词只追加到自定义绘图流程；预设安全限制可以单独配置。预设支持新增、修改、删除、示例图和多张参考图。

## 人设与每日状态

上传人设参考图后，可配置角色名称、描述、触发关键词、场景提示词、真人/动漫形象类型，以及每天稳定的穿搭、心情和时间段状态。人设拍照会使用这些信息并调用 AstrBot 当前人格完成自然收尾。

## 缓存与任务

成功记录会保存结果原图；图生图还会保存实际输入原图和提示词。记录可下载、收藏或锁定。自动清理只删除过期且未收藏、未锁定的记录；“清空未收藏”会立即删除所有未受保护记录。

批量任务支持立即停止、跳过继续、跳过但限次三种失败策略。后台模式提交任务后即可继续聊天，完成后插件主动发回图片。
