# 预设与提示词

## 预设来源

插件内置上游预设，并允许在聊天命令或 Dashboard 中新增、修改和删除自定义预设。预设列表会区分内置、已修改和自定义来源。

```text
#预设列表
#预设列表 我的
#预设列表 自带
#预设列表 改过
#预设列表 文字
#预设查看 手办化
#预设列表 说明
#预设列表 说明 手办
```

`#预设列表 说明` 会按“一行一个”的格式输出预设效果，适合快速查找；追加关键词可筛选。当前内置预设主要面向图生图，使用时应附带参考图。

## 指定渠道

在 Dashboard 的预设编辑窗口可选择多个现有渠道，并调整主用／备用顺序。绑定后仅在所选范围按顺序回退；未绑定时跟随会话与全局路由。旧版单渠道绑定继续有效。

优先级：请求显式指定渠道 → 预设有序渠道列表 → 当前会话渠道 → 全局默认。预设使用各渠道配置的模型，不受会话模型切换影响；显式指定的模型仍优先。渠道被删除、禁用或不允许参考图时明确提示修复绑定；额度耗尽时可尝试其余所选渠道。

原生配置在“【提示词与预设】预设设置”中同时维护渠道和图片参数。配置示例：`preset_generation_options: [{"preset": "动图画", "channel_ids": ["miku", "orb"], "image_output_format": "gif", "image_frame_count": 12, "image_frame_duration_ms": 170}]`。`channel_ids` 为有序列表，空列表表示跟随会话和默认路由。旧版 `preset_channel_bindings` 会自动迁移，旧导出仍可导入。

预设可独立设置输出格式与 GIF 帧参数，保存在 `preset_generation_options`，无需复制渠道。将输出格式设为 GIF 即在该预设的每次请求中传递动画参数；自动表示跟随渠道设置。详见 [GIF 预设配置](GIF.md)。完整配置导入导出会保留参数和渠道顺序，预设改名时同步迁移。

## 参考图配置

参考图的添加、查看、删除、清除、统计和列表都是管理员命令，需要在 AstrBot 配置 `admins_id`。普通用户可调用已配置好的预设。完整参数和兼容别名见[管理员命令](ADMIN_COMMANDS.md#预设参考图)。

预设可以绑定一张或多张参考图。启用“预设参考图”后，调用该预设会自动附带参考图；未绑定渠道时，如果当前渠道不允许参考图，请求会转到其他符合条件的回退渠道。已绑定渠道的预设会直接报错，请在绑定渠道开启参考图支持。

```text
#预设参考图添加 手办化
#预设参考图查看 手办化
#预设参考图删除 手办化 1
#预设参考图清除 手办化
#预设参考图统计
```

人设参考图使用独立的人设素材区，不会混入普通预设。

## 提示词处理顺序

用户请求通常按以下顺序组合：预设基础提示词 → 用户追加要求 → 提示词优化/翻译（如开启） → 反向提示词与安全限制 → 渠道协议转换。渠道只负责传输，不会改变 Dashboard 保存的原始预设。

## 翻译与优化

提示词翻译和优化是两个独立开关，可分别指定模型、系统提示词、地址和超时。处理服务不可用时默认回退到原始提示词，不会阻止绘图请求。

## 反向提示词

“自定义绘图反向提示词”主要作用于 `#画` 和 `#bnn`；预设可以额外设置安全限制。建议使用简洁、明确、符合上游服务规则的文本，避免把完整长篇指令重复粘贴到每个预设中。
