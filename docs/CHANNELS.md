# 渠道与协议

## 渠道字段

每条渠道包含：渠道 ID、接口模式、原生协议、基础地址、API Key、默认模型、文生图模型、带参考图模型、图生图上传格式、是否启用和是否允许回退。渠道列表从上到下就是优先顺序。

## 接口模式

| 模式 | 适用情况 |
| --- | --- |
| `auto` | 推荐。根据模型和请求类型选择优先协议，遇到明确协议不兼容时有限回退。 |
| `openai_image` | 优先使用 OpenAI Images 风格接口，适合 New API、GPT Image 等中转。 |
| `openai_chat` | 优先使用 Chat Completions，适合通过聊天接口返回图片的中转。 |
| `gemini_official` | 使用 Gemini 原生接口。 |
| `custom_endpoint` | 使用完整自定义地址，不跨协议猜测或回退。 |

原生协议还支持 Grok、Agnes、NovelAI、即梦等适配；选择后按服务商文档填写地址、模型和密钥。

## OpenAI 兼容地址

基础地址填写站点根地址，例如：

```text
https://example.com
```

不要填写完整动作路径（如 `/v1/images/generations` 或 `/v1/images/edits`），插件会根据文生图/图生图自动选择路径。自定义端点模式例外：它要求填写服务商提供的完整 URL。

纯文生图通常使用 generations；带参考图、人设图、头像或预设参考图时使用 edits。两者都需要服务商和模型实际支持，不能仅靠切换接口补出缺失能力。

## 回退规则

1. 先尝试当前会话指定的渠道；没有会话覆盖时使用主渠道。
2. 失败后按列表顺序尝试启用且允许回退的渠道。
3. 连续失败的渠道会进入短暂冷却，冷却期间自动跳过。
4. 鉴权失败、额度不足和内容安全拒绝是否继续回退由错误分类和对应开关决定。

## 会话级切换

`#通道` 和 `#模型` 默认只影响当前群聊或私聊。使用“全局”才修改全局默认值；使用“取消”“清除”“重置”或“跟随全局”可撤销当前会话覆盖。
