# 渠道与协议

## 渠道字段

每条渠道包含：渠道 ID、接口模式、原生协议、基础地址、API Key、默认模型、文生图模型、带参考图模型、图生图上传格式、是否启用和是否允许回退。渠道列表从上到下就是优先顺序。

## 接口模式

| 模式 | 适用情况 |
| --- | --- |
| `auto` | 推荐。根据模型和请求类型选择优先协议，遇到明确协议不兼容时有限回退。 |
| `openai_image` | 优先使用 OpenAI Images 风格接口，适合 New API、GPT Image 等中转。 |
| `openai_chat` | 优先使用 Chat Completions，适合通过聊天接口返回图片的中转。 |
| `gemini_official` | 使用 Gemini 原生接口。 |
| `custom_endpoint` | 使用完整自定义地址，不跨协议猜测或回退。 |

原生协议还支持 Grok、Agnes、NovelAI、即梦等适配；选择后按服务商文档填写地址、模型和密钥。

## OpenAI 兼容地址

基础地址填写站点根地址，例如：

```text
https://example.com
```

不要填写完整动作路径（如 `/v1/images/generations` 或 `/v1/images/edits`），插件会根据文生图/图生图自动选择路径。自定义端点模式例外：它要求填写服务商提供的完整 URL。

纯文生图通常使用 generations；带参考图、人设图、头像或预设参考图时使用 edits。两者都需要服务商和模型实际支持，不能仅靠切换接口补出缺失能力。

## 回退规则

1. 请求显式指定渠道时只使用该渠道；预设或自拍配置有序渠道列表时只在对应列表内回退；其余请求先尝试当前会话渠道，没有会话覆盖时使用普通默认路由。
2. 普通路由失败后按优先级尝试启用且允许回退的渠道；预设或自拍选定多个渠道时按所选顺序尝试备用，不受通用“允许回退”开关排除。
3. 连续失败的渠道会进入短暂冷却，冷却期间自动跳过。
4. 鉴权失败、额度不足和内容安全拒绝是否继续回退由错误分类和对应开关决定。

预设绑定的优先级高于会话渠道和会话模型。绑定方式见[预设与提示词](PRESETS.md#指定渠道)。输出格式、GIF 帧数、帧时长和复杂度可按预设独立配置并覆盖渠道默认，具体见 [GIF 预设](GIF.md)。

## 会话级切换

`#通道` 和 `#模型` 的查询和切换都需要 AstrBot 管理员。会话覆盖只影响当前群聊或私聊，使用“取消”“清除”“重置”撤销。只有通道命令支持“全局”修改全局主渠道；模型默认值在渠道页维护。关闭会话渠道选择后，渠道切换会改全局主渠道；关闭会话模型选择后，需直接编辑渠道模型。

`#通道 自动` 只清除当前会话覆盖，仍跟随已有全局主渠道；`#通道 全局 自动` 才将全局恢复为渠道列表顺序。接口模式、地址、密钥和默认模型均按渠道管理。完整语法见[管理员命令](ADMIN_COMMANDS.md#绘图渠道与模型)，单次指定渠道见 [bnn 指令](COMMANDS.md#bnn-本次指定渠道)。

## 迁移到其他服务器

渠道页导出包含真实 Key 和全部渠道参数，也包含主渠道、参考图优先渠道和自拍渠道顺序。目标服务器导入后保留本地用量。预设及其 GIF 参数请再通过设置页的脱敏配置迁移，同 ID 渠道的 Key 会保留；参考图素材需另行复制。操作步骤见[配置指南](CONFIGURATION.md#渠道迁移与测试)。
