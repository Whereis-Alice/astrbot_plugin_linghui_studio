# 排障手册

## 命令没有反应

确认消息使用了 AstrBot 顶层唤醒词，或直接 @机器人。若启用了命名空间，请使用“命名空间 + 命令”，例如 `#绘图 bnn 一只猫`。插件的 `extra_prefix` 只影响自定义绘图别名，不会绕过 AstrBot 的唤醒规则。

## 400、503 或渠道均失败

- 503、超时通常是渠道或上游服务暂时不可用，可使用 `#通道` 切换会话渠道验证。
- 400 可能是模型、尺寸、请求格式或服务商计费规则不支持；检查接口模式、模型和图生图上传格式。
- 多渠道已配置时，确认后续渠道开启“允许作为回退渠道”。
- OpenAI 兼容站点只填基础地址，不要把完整 `/v1/images/edits` 重复拼接进去。

## 图生图返回了原图

这通常是渠道回显了输入参考图，或服务端没有真正执行编辑。插件会检测结果与输入图是否相同并拒绝记录；请换用明确支持 Images edits/参考图的模型或渠道。

## 人设拍照失败但手办化成功

两者都属于图生图，但人设拍照会附带人设图、场景和更多提示词。请在渠道中开启“允许带参考图请求”，并设置带参考图模型；WebP/GIF 等素材会在上传时转换为 PNG。

## 头像获取失败

当前平台必须提供 QQ 数字账号。若平台无法返回头像，可直接发送图片作为参考图，或使用 `#bnn @用户` 让插件读取被艾特用户头像。

## 显示上游错误详情

可以开启“向用户显示上游错误详情”。聊天消息会保留状态码、错误码和端点路径，但会自动隐藏域名、主机名和 API Key。

## 图片已发出却提示超时

部分 QQ 适配器会在消息实际送达后才返回超时回执。请先确认群里是否已经收到图片；若已收到，成功记录和缓存通常仍会保留。
