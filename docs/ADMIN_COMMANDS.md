# 管理员命令

这里列出灵绘工坊现有的全部管理员专属聊天命令，并补充管理员查询他人额度的用法。普通绘图命令见[命令与使用](COMMANDS.md)。

## 管理员身份与前缀

管理员由 AstrBot 顶层配置中的 `admins_id`（管理员 ID 列表）识别。QQ 群主、群管理员、无限次数用户或 VIP 身份本身不授予这些命令的权限。大多数管理命令收到非管理员请求时不会回复。

下面使用 `#` 作为 AstrBot 唤醒词，请换成实际配置的唤醒词。若设置了插件命名空间，例如 `绘图`，命令写成 `#绘图 加用户额度 123456789 10`；关闭直接命令后需使用这种写法。

## 用户与群额度

| 命令 | 作用 | 兼容别名 |
| --- | --- | --- |
| `#加用户额度 <QQ号> <次数>` | 给指定用户追加次数，次数必须为正整数。 | `手办化增加用户次数` |
| `#加用户额度 @用户 <次数>` | 给艾特的用户追加次数，一次指定一个用户。 | 同上 |
| `#加群额度 <群号> <次数>` | 给指定群追加公共额度，次数必须为正整数。 | `手办化增加群组次数` |
| 群内 `#加群额度 <次数>` | 给当前群追加额度。 | 同上 |
| `#额度 <QQ号>` 或 `#额度 @用户` | 管理员查询指定用户余额，同时显示所在群的余额信息。普通用户只能查询自己的额度。 | `手办化查询次数` |
| `#总次数` | 查询全局上限、所有会话合计已用次数与剩余次数；普通用户也可查询。 | `全局次数` |
| `#总次数 <次数>` | 设置全局累计总上限，保留历史已用次数；0 暂停所有生图。 | `设置总次数` |
| `#增加总次数 <次数>` | 为现有全局总上限增加正整数次数。 | `加总次数` |
| `#总次数 不限` | 关闭全局上限，仍继续记录所有会话的累计次数。 | 同上 |
| `#统计` | 查看今日用户与群聊用量排行，各最多列出 10 项。 | `手办化今日统计` |

例如给某个用户加 10 次，给当前群加 50 次：

```text
#加用户额度 123456789 10
#加用户额度 @用户 10
#加群额度 50
#额度 123456789
#统计
```

个人余额按 QQ ID 保存，在群聊与私聊之间共用；它不是某个群的独立个人余额，也不是私聊专属余额。用户改昵称不会影响额度。开启相应额度限制后，绘图先尝试个人余额；个人余额不足时可使用已开启的群公共余额。需要重置或调整余额时可在 Dashboard 的“权限与额度”中操作。

补充额度不会自动把用户或群加入白名单，也不会开启私聊或额度限制。无限次数用户不会扣减个人/群余额，但仍受全局总次数限制。群额度仅在开启群额度限制后参与扣减。

## 绘图渠道与模型

这一组的查询、会话切换、取消和全局切换都需要管理员。

| 命令 | 作用 | 兼容别名 |
| --- | --- | --- |
| `#通道` | 查看启用的渠道列表、全局主渠道与当前会话覆盖。 | `渠道` |
| `#通道 <渠道ID或序号>` | 为当前会话选择优先渠道；失败时仍可回退。序号以查询列表为准，从 1 开始。 | 同上 |
| `#通道 取消` 或 `#通道 自动` | 清除当前会话覆盖，重新跟随全局配置。 | 同上 |
| `#通道 全局 <渠道ID或序号>` | 修改全局主渠道。 | 同上 |
| `#通道 全局 自动` | 清除全局主渠道选择，恢复渠道列表顺序。 | 同上 |
| `#模型` | 查看模型列表、全局默认模型与当前会话覆盖。 | `切换模型` |
| `#模型 <序号或模型名>` | 为当前会话选择模型；序号从 1 开始，也可直接输入完整模型名。 | 同上 |
| `#模型 取消` | 清除当前会话模型覆盖。 | 同上 |
| `#模型 全局 <序号或模型名>` | 修改顶层全局默认模型。 | 同上 |
| `#接口模式 <模式>` | 修改顶层共享/兼容接口模式。 | `切换API模式` |

```text
#通道
#通道 2
#通道 全局 primary
#通道 全局 自动
#模型
#模型 gpt-image-2
#模型 全局 gpt-image-2
#接口模式 auto
```

会话范围取决于 AstrBot 的会话划分，通常是当前群或私聊；有效期由“会话级选择有效期”配置决定。关闭“会话级模型选择”或“会话级渠道选择”后，普通切换也会写入全局配置。`#通道 自动` 跟随已有全局主渠道；若要让全局按列表顺序调度，请用 `#通道 全局 自动`。

接口模式可填 `auto`、`openai_image`、`openai_chat`、`gemini_official`、`custom_endpoint`。旧名称 `generic` 对应 `openai_chat`，`gemini` 对应 `gemini_official`。命令只修改顶层模式，已显式设置接口模式的渠道继续使用自身配置；修改某条渠道请在 Dashboard 的“绘图渠道”中操作。

全局模型命令修改顶层默认模型，不会批量覆盖每条渠道的模型字段。渠道设置的文生图/带参考图专用模型及协议规则也可能影响实际模型，可在成功记录中查看最终使用的渠道和模型。详见[渠道与协议](CHANNELS.md)。

## 预设提示词

| 命令 | 作用 | 兼容别名 |
| --- | --- | --- |
| `#预设添加 <名称>:<提示词>` | 新增或覆盖同名预设，并保存到配置。名称与提示词之间使用英文冒号 `:`。 | `lm添加`、`lma` |
| `#预设删除 <名称>` | 删除用户预设或配置覆盖，并清除该名称绑定的参考图。 | `lm删除`、`lmd`、`lm删`、`删除预设` |

```text
#预设添加 水彩肖像:将参考图主体转换为柔和的水彩肖像，保留身份特征
#预设查看 水彩肖像
#预设删除 水彩肖像
```

`#预设列表`、`#预设列表 说明` 和 `#预设查看` 可供普通用户使用。删除覆盖后，同名内置预设可能恢复；仅来自固定内置来源的预设会拒绝删除。

## 预设参考图

这些命令操作预设绑定的输入参考图，查看也需要管理员。预设名应不含空格；序号从 1 开始。

| 命令 | 作用 | 兼容别名 |
| --- | --- | --- |
| `#预设参考图添加 <预设名>`，同时发送或引用图片 | 追加到已存在的预设，不覆盖已有图片。 | `lmref添加`、`添加参考图` |
| `#预设参考图查看 <预设名>` | 发回参考图，单次最多显示 5 张。 | `lmref查看`、`查看参考图` |
| `#预设参考图删除 <预设名> <序号>` | 删除指定的一张参考图。 | `lmref删除`、`删除参考图` |
| `#预设参考图清除 <预设名>` | 清除该预设全部参考图。 | `lmref清除`、`清除参考图` |
| `#预设参考图统计` | 查看预设数、图片数、占用空间和数量排行。 | `lmref统计`、`参考图统计` |
| `#预设参考图列表` | 列出有参考图的预设及张数，并标记对应提示词是否存在。 | `lmref列表`、`参考图列表` |

```text
#预设参考图添加 水彩肖像
#预设参考图查看 水彩肖像
#预设参考图删除 水彩肖像 1
#预设参考图清除 水彩肖像
```

添加时请附图或回复含图片的消息。绑定完成后，启用“预设参考图”才会在调用该预设时自动使用。

## 人设素材

| 命令 | 作用 | 兼容别名 |
| --- | --- | --- |
| `#人设参考图添加`，同时发送或引用图片 | 追加人设素材，独立于普通预设参考图保存。 | `添加人设图` |
| `#人设参考图查看` | 发回人设参考图，单次最多显示 5 张。 | `查看人设图` |
| `#人设参考图清除` | 清除全部人设参考图。 | `清除人设图` |
| `#人设状态` | 查看启用状态、名称、描述、照片风格、参考图数、场景数与触发词。 | 无 |

单张人设图的删除在 Dashboard 的“人设与参考图”中操作。`#人设场景列表`（别名 `场景列表`）可供普通用户查看场景，不需要管理员身份。

## 共享密钥池

| 命令 | 作用 | 兼容别名 |
| --- | --- | --- |
| `#添加密钥 <Key1> [Key2…]` | 向顶层 `api_keys` 追加一个或多个密钥，以空格分隔。 | `手办化添加key` |
| `#密钥列表` | 查看共享密钥池数量及每个密钥的前 8 个字符，不显示完整密钥。 | `手办化key列表` |
| `#删除密钥 <序号>` | 删除共享密钥池中的一个密钥，序号从 1 开始。 | `手办化删除key` |
| `#删除密钥 all` | 清空当前共享密钥池。 | 同上 |

这组命令不编辑某条渠道自己的 Key。兼容单接口和未单独填写密钥的渠道可使用共享池；渠道已填写自己的 Key 时优先使用自身配置。旧配置尚未迁移且顶层池为空时，列表/删除命令会使用对应的旧密钥池。

新增密钥建议在 Dashboard 中填写；使用聊天命令时请在机器人私聊中操作，避免完整密钥留在群消息里。

## 示例图缓存与排障

| 命令 | 作用 | 兼容别名 |
| --- | --- | --- |
| `#预设图片统计` | 查看预设列表展示用示例图的数量和占用空间。 | 无 |
| `#预设图片清理 [天数]` | 按文件修改时间清理超过指定天数的示例图，默认 30 天。 | 无 |
| `#上下文状态` | 查看插件会话数、当前会话最近消息与图片上下文、智能判断配置和消息摘要。 | 无 |
| `#清除上下文` | 清除当前会话的插件上下文及图片上下文缓存。 | 无 |
| `#测试智能判断 <测试文本>` | 分析任务类型、置信度和理由，不实际生图。 | 无 |

```text
#预设图片统计
#预设图片清理 30
#上下文状态
#测试智能判断 把刚才那张图片改成水彩风
#清除上下文
```

“预设图片”指预设列表的示例图，不是绑定参考图，也不是 Dashboard 的成功记录缓存。成功记录的清理、收藏和锁定见 [Dashboard 指南](DASHBOARD.md)。`#清除上下文` 只操作插件维护的当前会话上下文，不会删除 AstrBot 原生聊天历史。
