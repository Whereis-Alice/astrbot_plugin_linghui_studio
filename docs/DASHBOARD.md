# Dashboard 指南

Dashboard 从 AstrBot 插件页面进入。页面分为概览、文生图记录、图生图记录、收藏、任务中心、创作、人设与参考图、运行设置等模块。

## 记录

- 文生图和图生图分开查看。
- 图生图记录会显示输入原图、结果图、提示词、用户/群 QQ ID、名称快照、渠道、模型和时间。
- 支持按群聊或个人筛选，群名和昵称只作为展示信息，QQ ID 才是归属依据。
- 成功图片可直接下载；收藏或锁定后不会被自动清理。
- 图生图旧记录没有输入原图时会明确标注“原图不可用”，不会伪造原图。

## 配置

“运行设置”可修改兼容接口、默认模型、分辨率、命令命名空间、手动指令冷却、错误详情显示、请求者标注和缓存保留期。

“绘图渠道”可新增、排序、启停和测试渠道；“提示词与预设”管理预设及参考图；“人设与参考图”管理人设素材、场景和每日状态；“权限与额度”管理白名单、黑名单、用户/群额度、签到和无限次数名单。

## 主题

主题选择会保存到插件配置，重新打开页面后自动恢复。内置深色、浅色、爱丽丝、黑客终端和星云主题，均配有适配主题的网络背景；界面密度支持紧凑/宽松模式。
