# Dashboard 指南

Dashboard 从 AstrBot 插件页面进入。页面分为概览、文生图记录、图生图记录、收藏、任务中心、创作、人设与参考图、运行设置等模块。

## 记录

- 文生图和图生图分开查看。
- 图生图记录会显示输入原图、结果图、提示词、用户/群 QQ ID、名称快照、渠道、模型和时间。
- 支持按群聊或个人筛选，群名和昵称只作为展示信息，QQ ID 才是归属依据。
- 成功图片可直接下载；收藏或锁定后不会被自动清理。
- 图生图旧记录没有输入原图时会明确标注“原图不可用”，不会伪造原图。

### 查看大图

在文生图、图生图、收藏或概览的最近作品中，点击图片上的“查看大图”即可打开大图窗口。图生图记录展开“输入原图”后，也可以点击其中实际缓存的输入图。

- 默认适应窗口，完整显示画面；点击 **100%** 查看实际像素，使用 **+ / −** 缩放，放大后拖动或滚动查看细节。
- 双击图片可切换适应窗口与 100%；键盘 `0` 为适应窗口、`1` 为 100%、`+ / −` 为缩放、`Esc` 关闭。
- 点击“下载原图”保存原始缓存文件。关闭大图不会跳走，也不会改变原列表的滚动位置。
- 只有点击时才读取大图，列表仍只加载小缩略图。常见格式直接查看原始文件；需要转换或缩小的图片会标明“高清预览”，不会冒充原图。过大的文件会提示改用下载查看。
- 缓存已清理的图片无法打开；旧记录中的“当前参考图候选”不代表当次输入图，因此不提供历史原图查看入口。

## 配置

“运行设置”可修改命令命名空间、手动指令冷却、错误详情显示、请求者标注和缓存保留期。接口、模型和分辨率在渠道条目中维护。

“绘图渠道”可新增、排序、启停和测试渠道；“提示词与预设”管理预设及参考图；“人设与参考图”管理人设素材、场景和每日状态；“权限与额度”管理白名单、黑名单、用户/群额度、签到和无限次数名单。

## 渠道健康

成功、失败和回退成功按一次请求在一个渠道上的最终结果累计；同渠道内部的模型与 Key 重试合并计数。P50/P95 取该渠道最近 200 次成功请求的耗时，包含同渠道内重试。没有可靠耗时样本时显示“暂无耗时样本”。这些统计属于本服务器，和每天清零的日额度分别记录。

统计保存在插件数据目录 `channel_health.json`，插件热重载和重启后保留。首次升级从仍保留的任务与成功记录中恢复有渠道尝试明细的数据，并去除重复记录；旧版未记录或已清理的请求无法补齐。页面会显示恢复情况和落盘异常。删除渠道后隐藏其卡片，统计仍按渠道 ID 保留。渠道导入导出不携带统计与本地用量。

## 主题

主题选择会保存到插件配置，重新打开页面后自动恢复。内置深色、浅色、爱丽丝、黑客终端和星云主题，均配有适配主题的网络背景；界面密度支持紧凑/宽松模式。
