# 数据与隐私

## 保存内容

为支持 Dashboard、统计和任务恢复，插件可能保存：

- 成功结果图片和图生图输入原图；
- 用户 QQ ID、群号、群名和昵称快照；
- 请求提示词、预设名、渠道、模型、尺寸、时间和任务状态；
- 用户/群额度、签到记录、会话级模型与渠道覆盖。

群名和昵称仅用于展示，用户归属、额度和统计始终按 QQ ID/群号识别。群友改名不会生成新的用户记录。

## 缓存清理

成功记录按“缓存保留天数”自动清理。收藏或锁定的记录不会被自动清理；“清空未收藏”会删除所有未收藏且未锁定的记录，包括图生图输入原图。删除操作不可恢复，请先下载需要保留的图片。

## 密钥与日志

API Key 保存在 AstrBot 插件配置中，Dashboard 不会回显完整密钥。开启“向用户显示上游错误详情”时，聊天消息会保留状态码和错误正文，但会自动脱敏域名、主机名和密钥；管理员日志仍可用于本地排查。

## 数据位置

实际目录由 AstrBot 为插件分配，通常包含插件配置、数据文件、缓存图片、任务记录和参考图。迁移或备份时请同时备份配置与数据目录，并注意不要把密钥提交到公开仓库。
