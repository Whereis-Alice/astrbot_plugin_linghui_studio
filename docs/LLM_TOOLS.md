# LLM 工具

插件提供绘图、人设拍照、头像参考图和图片转 PDF 等 LLM 工具。工具调用会复用权限、额度、渠道回退、成功记录和请求者标注规则。

## 执行方式

- **wait**：工具等待图片完成后再返回结果，适合需要在同一轮对话中立刻引用图片的场景。
- **background**：提交任务后立即返回，Bot 可以继续处理聊天；图片完成后由插件主动发回，适合群聊和长耗时渠道。

后台完成消息可选择只发图片，或附带请求者/简短完成信息。无论哪种模式，成功图片都会进入 Dashboard 记录。

## 冷却与人格

LLM 工具使用 `llm_cooldown_seconds`，手动指令使用 `command_cooldown_seconds`；两套冷却相互独立。人设拍照和自拍类自然语言请求会沿用 AstrBot 当前人格进行收尾，不会强制改成插件固定口吻。

## 批量任务

批量请求支持立即停止、跳过继续、跳过但限次。后台批量任务会逐张发回结果，并在任务中心显示成功、失败和跳过数量。
